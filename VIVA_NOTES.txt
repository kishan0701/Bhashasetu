2. PROBLEM — YEH PROJECT KYO BANAYA?
----------------------------------------------------------------

UNESCO ke mutabiq India ki 197+ languages aaj ENDANGERED hain.
Jab ek language marti hai, uske saath:
  - Lok kathayen (Folk Stories)
  - Proverbs (kehawatein)
  - Pronunciations (uccharan)
  - Cultural knowledge
  ...sab kuch humesha ke liye khatam ho jaata hai.

Problems jo humne solve ki:
  1. Kai languages sirf maukhik hain — koi written script nahi
  2. Research scattered hai — academic papers me band
  3. Koi engaging platform nahi tha young generation ke liye
  4. Community verification ka koi system nahi tha

3. TECHNOLOGIES USED (TECH STACK)
----------------------------------------------------------------

FRONTEND FRAMEWORK:
  -> React 19       : UI banane ke liye (component-based)
  -> TypeScript     : Type-safe JavaScript (bugs kam hoti hain)
  -> Vite           : Super fast dev server & build tool

  -> Custom CSS          : Glassmorphism, glow animations
  -> Google Fonts        : Outfit, Plus Jakarta Sans,

UI / ANIMATIONS:
  -> Framer Motion  : Smooth page animations & transitions
  -> Lucide React   : Modern icons library
  -> Recharts       : Charts & graphs (Dashboard page pe)

MAP:
  -> Leaflet        : Interactive geographic map
  -> React Leaflet  : Leaflet ka React wrapper
  -> OpenStreetMap  : Free map tiles — no API key needed

STATE MANAGEMENT:
  -> React Context API   : Global app state (AppContext.tsx)
  -> Mock Data           : mockData.ts — simulated database

AUDIO:
  -> Browser Web Audio API : In-browser voice recording
  -> HTML5 Audio           : Playback with waveform visualizer

DEVELOPER TOOLS:
  -> Serena LSP     : Code intelligence & symbol navigation
  -> ESLint/oxlint  : Code quality checker
  -> npm            : Package manager

5. DATA STRUCTURE
----------------------------------------------------------------

Hum Mock Data use kar rahe hain (cep-app/src/data/mockData.ts).
Real project me Supabase ya Firebase connect hoga.

Types defined in: cep-app/src/types/index.ts

Language {
  id, name, nativeName, region, state
  speakers (total count), status
  coordinates [lat, lng]  <- map ke liye
  wordCount, storyCount, audioCount
}

Word {
  id, word, meaning, pronunciation (IPA format)
  language, partOfSpeech, exampleSentence, verified
}

Story {
  id, title, language, content, englishTranslation
  category, readingTime, narrator, verified
}

AudioRecording {
  id, title, description, duration
  language, region, speaker, category, playCount
}

11. VIVA Q & A — EXPECTED QUESTIONS
----------------------------------------------------------------

Q: Aapka project kya hai?
A: BhashaSetu ek web-based digital archive hai jo Maharashtra ki
   endangered regional languages ko preserve karta hai. Isme
   words, stories, audio recordings, interactive map, aur
   community contribution system hai.

Q: Kon si technology use ki?
A: React 19 + TypeScript (frontend), Tailwind CSS (styling),
   Vite (build tool), Leaflet (map), Framer Motion (animations),
   Recharts (charts), React Context API (state management).

Q: Database kya hai?
A: Abhi mock data file (mockData.ts) use kar rahe hain —
   prototype phase hai. Production me Supabase (PostgreSQL) ya
   Firebase integrate karenge.

Q: Kya innovative hai is project me?
A: 1) In-browser voice recording — koi app install ki zaroorat
      nahi.
   2) Dual-language story reader — original + English saath.
   3) Animated audio waveform visualizer.
   4) Community contribution + admin moderation pipeline.
   5) Geo-linguistic map with dialect location pins.

Q: Endangered language preserve kyun?
A: UNESCO ke mutabiq jab language marti hai, uske saath culture,
   folklore, ecological knowledge sab khatam hota hai. Digital
   archiving ek long-term sustainable solution hai.

Q: App responsive hai?
A: Haan — Tailwind CSS breakpoints use kiye (sm, md, lg).
   Mobile 360px se desktop 4K tak kaam karta hai.
   Mobile me hamburger menu hai.

Q: TypeScript kyun?
A: Compile time pe bugs pakad me aati hain — runtime errors
   kam hote hain. Component props clearly typed hote hain.
   Team collaboration me helpful hota hai.

Q: Security kaise handle ki?
A: Submissions directly publish nahi hoti — admin moderation
   queue se jaati hain. Future me JWT authentication add hoga.

Q: SPA kya hota hai?
A: Single Page Application — ek hi HTML page load hoti hai,
   aur React Router se pages switch hote hain bina full reload
   ke. Fast aur smooth feel deta hai.

Q: Vite kyun use kiya Next.js ki jagah?
A: Audio playback aur Leaflet maps purely client-side hain,
   SSR ki zaroorat nahi thi. Vite ka HMR (Hot Module Replace)
   development me bahut fast hota hai.
